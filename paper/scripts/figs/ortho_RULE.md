# 图 2d / 补充图：代表性正交视图的选法（2026-11-07，写于运行任何选取脚本之前）

1. 体积选法（主代理转述的投稿分析方案 4.6 节）：gt 协议、种子 0（S1 07992b55、二维 81116913、原版 b5973303）。
   每套计算每个测试体积的 F1@0.5（S1、二维均按规则 T 选阈值，与 $NUCSEG3D_SCRATCH/r6/test_r6.py recs() 相同；原版用固定 cp−2，与正文 --base_fixed 一致），
   取 d = F1(S1) − F1(二维)；选 d 最接近该套 d 的中位数的体积（中位数取 numpy.median；并列时取 id 字典序最小者）。13 套各选一个。
2. 主图选哪几套：只在 12 个合并的数据集里选（mesoSPIM 只有 1 个测试体积、不进合并，放补充图）。
   按所选体积的 z/xy 体素比（rows.json 的 ratio）从小到大排序（并列按数据集名），取排序位置 round(linspace(0, 11, 5)) = 0, 3, 6, 8, 11 的 5 套。
3. 掩膜：阈值 t 由 recs() 给出；t = −2 用 npz 里存的 pred，否则按 test_r6.hits() 的方式由存下的 dP、cp 重算（cellpose dynamics.compute_masks，参数同 hits）；
   再删去体积 < 0.15 × 预期体积的碎块（同 hits）。
4. 显示：三个中心切面（xy 取 z 中心、xz 取 y 中心、yz 取 x 中心），按体素物理尺寸显示纵横比；
   为了看得清，每个切面以体积中心为中心裁成边长 min(全幅, 8d) 像素的方窗（d 为 npz 里的直径，xy 像素；z 方向按 z/xy 换算）。
   图像按该切面 1–99.5 百分位线性拉伸，不做其他处理。轮廓：真值白色，S1 蓝、二维橙、原版灰（全文配色）。

## 补记（2026-11-07，看到第一次选取结果之后，事后修改，须在图注/回报中说明）
第一次运行按“并列取 id 字典序最小”选出的 bbbc050（test_Emb1_t001，2 个核）和 blastospim（2 个核，中心切面无核）不具代表性：
